# Source provenance and release rights

This package integrates the three HEATWISE scripts supplied by Leonel Garro Linck. Original copies are included for audit and regression tests. The official unmixing repository was consulted to verify its input contract; this package does not include or execute its FCLS implementation.

No license is asserted over the original scripts. Project owners must choose the appropriate release license and confirm GUSL access/distribution rights before public delivery. Only generated synthetic spectra are bundled, not the real GUSL database.
