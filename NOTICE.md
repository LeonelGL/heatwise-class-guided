# Source provenance and release rights

This review package integrates the three HEATWISE scripts supplied by Leonel Garro
Linck. Original source copies are included for audit and regression testing.
Selected official repository files are included at the commit recorded in
`docs/PROVENANCE.json`; FCLS calculations are not rewritten.

No new license is asserted over the original scripts or upstream code. Project
owners should confirm the appropriate license and GUSL access/distribution rights
before public release. The synthetic library contains generated test spectra only;
it does not redistribute GUSL. No confidential credentials are included.
