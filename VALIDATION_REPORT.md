# Validation report — HEATWISE class-guided v0.3.2

## Executable interface under test

The integrated processor extracts image-derived candidate signatures and
matches them to GUSL using FULL common-finite spectral bands. It selects
15 bands **from FULL-selected endmembers**, independently reruns class
matching on those 15 wavelengths (MASK3), and exports separate FULL and
MASK3 endmember libraries on **the complete usable scene wavelength grid**.

Primary products: selected_endmembers_FULL.xlsx,
selected_endmembers_MASK3.xlsx, the identical FULL compatibility alias
selected_endmembers.xlsx, selected_bands.json and mask3_matching_bands.json.
Diagnostics, quality flags, run_summary.json and STAC metadata are supporting
outputs. No reduced image, MAT file, FCLS execution, abundance raster or
material-classification raster is generated by this application.

## What has NOT been established

- ESA hosting-platform acceptance, a formal ESA certification or an
  official versioned GitHub Release.
- An actual HySUPP FCLS abundance/classification run using exported
  signatures. Only spectral alignment and interface preflight were checked.
- Accuracy/ground-truth validation of the extracted material labels.
  Fallback identifications are provisional.
- Exact numerical repeatability across independently created GitHub runners.
  Earlier runs showed differences in some extracted candidate spectra.
- Legal authorization to redistribute real GUSL spectra or the Sepolia scene,
  or a selected LICENSE for the source code.

## Release test contract

After each change, execute:

    python -m pip install -r requirements-lock-python311.txt
    python -m pytest tests -q
    python -m cwltool --validate cwl/workflow.cwl
    python -m cwltool --validate cwl/local/workflow.cwl
    docker build -t heatwise/class-guided:0.3.2 .
    python -m cwltool --outdir results/ci cwl/workflow.cwl examples/job_synthetic.yml
    python tools/validate_outputs.py results/ci/results

The pull-request workflow additionally generates versioned EOAP CWLs,
packs a self-contained CWL using cwltool --pack, and verifies source-file
checksums. The formal release workflow also executes the final versioned
CWL with the versioned Docker image **before publishing it**.

Real datasets were removed from the delivery branch until redistribution is
authorized. They remain accessible to the original author through older Git
commits; removal in a new commit does **not** purge already published Git
history. Real-scene tests require authorized stage-in. CI uses synthetic
fixtures and cannot substitute for real scientific validation.

## Detailed scientific limitations

The FULL comparison uses a global finite-band intersection with GUSL, not
all 250 image bands. PCHIP does not extrapolate outside each signature's
measured limits. The procedure can retain spectrally similar signatures,
and some class labels have overlapping materials. The 15 chosen bands
optimize a proxy for class discrimination, not an independent FCLS
abundance-error objective. See docs/DUAL_SELECTION_V032.md and
docs/GENERAL_CLASS_FALLBACK.md for method and quality flags.
